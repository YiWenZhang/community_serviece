# 社区银龄服务前端

Vue 3、TypeScript、Vite、Pinia、Vue Router、Axios、Element Plus。页面连接真实Spring Boot接口，没有Mock数据，不保存密码或个人业务数据到localStorage。

最简启动步骤见项目根目录的[快速启动文档](../快速启动.md)。

```powershell
npm.cmd ci
npm.cmd run dev
```

默认访问`http://127.0.0.1:5173`，`/api`由Vite代理到`http://127.0.0.1:8080`，Cookie及CSRF自动处理。需要不同后端端口时，在本目录创建`.env.local`设置`VITE_API_TARGET=http://127.0.0.1:8081`后重启前端。

已提供：登录、角色菜单、工作台、档案登记编辑、接种核验、通知创建激活、触达及凭证上传、满意度、跟进处理、统计与报表下载、用户启用及密码设置、规则维护。当前通知对象选择器显示本人最近100条档案；导出列表只显示本次页面会话的申请。

1.1.0新增政策知识库、政策问答助手、AI模型配置。管理员上传并查看解析，网格员通过对话查看原文引用，最高权限管理员配置和切换模型。详见[政策问答启动说明](../政策问答启动说明.md)。

```powershell
npm.cmd run build
```

包含Vue与TypeScript类型检查，产物位于`dist`。开发环境同源代理已配置；生产部署需另配置Nginx的`/api`转发，不能直接双击dist/index.html运行。

本项目`.npmrc`使用官方源并绕过本机已失效的旧代理，仅作用于本项目。安装锁文件已提供。

浏览器验证见[浏览器验证记录](浏览器验证记录.md)，已覆盖真实后端的账号启用、档案登记、通知到跟进闭环、月报下载、权限及窄屏布局。测试使用隔离数据库，未向已有3306业务库写入验证数据。
