# 后端实现及验证记录

验证日期为2026年10月16日。实现目录为backend，独立服务名community-service，版本1.0.0。服务包含31张既有表对应的非AI业务，不包含AI依赖及AI接口。

## 构建环境

本机Java22.0.2、Maven3.9.16、MySQL8.0.42；Java编译目标21。依赖采用Spring Boot4.1.1、Springdoc3.1.1及Apache POI5.4.1。生成可执行Spring Boot JAR，并提供Java21运行时Dockerfile。Docker镜像构建本次未执行，不能把Dockerfile的存在当作镜像验证通过。

## 自动化测试

实际启用RUN_MYSQL_TESTS，连接独立13316实例及以_test或_regression结尾的隔离测试数据库。没有把测试指向用户现有3306业务库，也未自动激活该业务库里的应用用户。

| 测试类型 | 数量 | 结果 |
| --- | --- | --- |
| 加密与校验测试 | 3 | 全部通过 |
| 真实MySQL集成测试 | 14 | 全部通过 |
| 打包JAR的HTTP端到端检查 | 13 | 全部通过 |

Maven最终回归为17项，失败0、错误0、跳过0。HTTP检查通过独立脚本执行，结果不混入Maven测试数量。Maven命令没有RUN_MYSQL_TESTS时会有意跳过真实库测试，不能据此声称完成数据库集成验证。

基础测试覆盖AES-GCM随机nonce、加密认证及篡改检测、HMAC稳定性、个人信息文本拦截、BIGINT输出及version整数格式。

MySQL集成测试覆盖编号与已有密钥兼容、序列分配、统计员及跨负责人越权、触达幂等与内容冲突、上门确认缺凭证、接收不修改接种事实、原子移交、历史事件统计、未知资格分母、规则生成防重、满意度追加、附件人工脱敏、移交后附件访问、JSON语义幂等、预约前提醒保留、报表幂等，以及数据库错误后的完整回滚。多个断言合并在同一测试方法，因此覆盖点数量多于14。

HTTP检查覆盖未登录401、无CSRF403、真实Cookie登录、管理员与统计员的业务隔离、网格员查询及加密编号展示、登记、跟进重复提交、统计接口、XLSX和DOCX持久作业及鉴权下载、OpenAPI与Swagger页面、注销失效。文件下载经过OOXML压缩包结构检查，未做Word或Excel客户端逐页视觉排版验收。

## 接口文档

提供49个HTTP操作，分布在43条路径。详细说明在API接口文档.md，OpenAPI文件从运行中的服务导出，默认服务器地址已调整为127.0.0.1:8080，适合导入API调试工具。服务启动后也能通过/v3/api-docs获取当前版本。

## 数据与安全措施

源码无MySQL明文密码。启动脚本通过本机隐藏输入读取数据库及首次应用密码，只在当前进程及子进程环境中传递。示例加密密钥只用于原三条虚构档案，与数据库账号密码无关。

Session及CSRF实现、每次请求权限读取、账号变更使会话失效、业务数据范围、附件鉴权、编号加密、独立核验事实、脱敏审计、私有文件目录及队列租约均已实现。生产使用前仍需配置HTTPS、专用数据库账号、真实密钥与备份、运行环境及业务授权。

当前未接入短信供应商、卫生服务中心和街道报表平台；SMS不会返回假成功。图片结构校验和重新编码不等于第三方杀毒服务，也不能代替人工确认脱敏。没有进行真实生产压力测试、故障恢复演练、容器部署或多实例Session验证。

## 运行与后续AI服务

本地运行参见backend/README.md。启动脚本连接已有数据库，不建表、不覆盖样例。首次由操作者自行设置admin_demo的应用密码，再通过权限接口启用业务用户。

本业务服务作为一个可独立部署的微服务，内部保持通知和跟进的本地事务。未来AI服务独立部署并拥有政策及问答数据，通过明确接口交互。当前不提供可由任意AI调用的老人信息后门，也不要求本服务等待AI在线。
